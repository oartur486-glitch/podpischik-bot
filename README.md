# Подписчик — Telegram-бот на Netlify

Бот следит за подписками и напоминает о списаниях и об окончании пробных периодов.
Работает на Netlify Functions + бесплатной базе Neon. Зависимостей нет, сборки нет.

## Что внутри

| Файл | Зачем |
|---|---|
| `netlify/functions/bot.mjs` | принимает сообщения из Telegram (webhook) |
| `netlify/functions/remind.mjs` | раз в час проверяет даты и шлёт напоминания |
| `netlify/lib/core.mjs` | общий код: Telegram, база, даты, разбор текста |
| `netlify.toml`, `public/index.html` | настройки Netlify и страница-заглушка |

## Запуск с телефона (~15 минут)

Все шаги делаются в браузере. Если сайт открывается в мобильной версии и что-то не нажимается, включите «Версия для ПК».

**1. Токен бота.** В Telegram откройте @BotFather → `/newbot` → имя и username → скопируйте токен.

**2. База.** Зайдите на neon.com (вход через Google, карта не нужна) → создайте проект → нажмите **Connect** → скопируйте строку, которая начинается с `postgresql://`. Только саму строку, без `psql` и кавычек.

**3. Код на GitHub.** Создайте новый репозиторий на github.com. Затем для каждого из 5 файлов: **Add file → Create new file**, в поле имени впишите путь целиком (слэши сами создадут папки), вставьте содержимое, нажмите **Commit changes**:

- `netlify.toml`
- `public/index.html`
- `netlify/functions/bot.mjs`
- `netlify/functions/remind.mjs`
- `netlify/lib/core.mjs`

**4. Netlify.** **Add new project → Import an existing project → GitHub** → выберите репозиторий. Build command оставьте пустой, остальное подхватится из `netlify.toml`. Нажмите Deploy.

**5. Переменные.** В проекте: **Project configuration → Environment variables → Add a variable**. Три штуки:

- `BOT_TOKEN` — токен из шага 1
- `DATABASE_URL` — строка из шага 2
- `WEBHOOK_SECRET` — любой набор латинских букв и цифр, 20+ символов (придумайте сами и запомните)

После этого **Deploys → Trigger deploy → Deploy project**, чтобы функции увидели переменные.

**6. Подключение.** Один раз откройте в браузере (подставьте адрес своего сайта и свой секрет):

```
https://ИМЯ-САЙТА.netlify.app/.netlify/functions/bot?setup=ВАШ_СЕКРЕТ
```

Должно появиться: таблицы готовы, имя бота, webhook установлен. Это создаёт таблицы в базе и подключает бота к Telegram.

**7. Проверка.** Откройте бота в Telegram и отправьте `/start`, затем `Netflix 9.99 USD 15 месяц`.

## Как пользоваться

- Меню внизу экрана (появляется после `/start`): **➕ Добавить**, **📋 Список**, **⚙️ Настройки**, **❓ Помощь**.
- Добавить кнопками: «➕ Добавить» → сервис из готовых (Netflix, YouTube Premium, Spotify и др.) или своё название → сумма текстом (валюту можно выбрать кнопкой) → дата кнопкой (сегодня, завтра, через неделю, число месяца) или текстом → период и триал кнопками.
- Добавить текстом: одним сообщением `Netflix 9.99 USD 15 месяц`. Чего не хватает, бот спросит сам.
- Пробный период: добавьте слово `триал`, дата — когда он заканчивается. Напоминание придёт до начала списания.
- Список: все подписки, суммы в месяц и в год, кнопки удаления и кнопка «➕ Добавить подписку».
- Настройки меняются одним нажатием: время напоминаний (по умолчанию 9:00), за сколько дней (3, 1 и в день списания), валюта по умолчанию (SEK), часовой пояс (Europe/Stockholm). Своё значение — командами `/time`, `/days`, `/cur`, `/tz`.

## Важно знать

- **Кредиты Netlify.** На бесплатном тарифе кредиты общие на месяц, и каждый выкат тратит их (в прошлый раз я находил цифру 15 кредитов за продакшен-деплой из 300 в месяц, сверьте на странице Usage). Любое изменение файла на GitHub запускает новый деплой, поэтому не правьте код без нужды.
- **Напоминания по времени.** Функция запускается каждый час по UTC, а 9:00 считается по часовому поясу каждого пользователя. Если час пропущен, напоминание придёт при следующем запуске в тот же день, дублей нет.
- **Не проверено вживую.** Код прогнан на подставных Telegram и базе, но с настоящими Neon, Telegram и Netlify я работать не мог. Если на шаге 6 появится красная строка, пришлите её текст.
